Токены виджета Киноплан

Собраны из вычисленных стилей и CSS-деклараций живого виджета 20.11.2026. Это основа UI-кита: каждый элемент ниже должен собираться только из переменных.

Примитивы · серый

Серая шкала из виджета: 25…900. Совпадает с системной палитрой iOS, которую Киноплан использует напрямую.

Примитивы · акцент и статусы

Акцент основной кнопки #0A7AFF, в теме vkgid — #0077FF. Ошибка #FF3B30, предупреждение #CF7900. Зелёный и зоны зала — расширение для редизайна.

То, чем пользуются компоненты. Переключите тему — значения подменяются, имена остаются.

Кнопки и поля

Высота 48 px — как у основной кнопки виджета. Радиус 8 px — самый частый радиус в их CSS (42 объявления).
