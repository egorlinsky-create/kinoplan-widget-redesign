# Виджет продажи билетов «Киноплан» — UX-аудит и редизайн

## Как открыть прототип

Открыть `prototype/index.html` в браузере — сборка не нужна, зависимостей нет.

- Тап по любому сеансу открывает схему зала.
- Кресла кликабельны, лимит 6 мест, сумма считается на лету.
- «Оформить» → оформление (валидация полей при нажатии «Оплатить»).
- «Оплатить» → экран оплаты; табы «Карта / СБП»; затем «Билеты готовы».
- Кнопка «Начать заново» в верхней панели возвращает к афише.
- Переключатель «Десктоп» показывает адаптив: две колонки, панель заказа справа.

## Главное в двух строках

Было: 4 экрана виджета, ввод данных без сводки заказа, три юридических чекбокса, заблокированная кнопка без объяснений, canvas-зал с креслами 20 px и просьба «вернитесь на этот экран после оплаты».
Стало: 3 шага после выбора сеанса, сводка заказа на всех шагах, одно согласие, активная кнопка с инлайн-валидацией, зал на весь экран с ценовыми зонами и ценой на ховере/тапе, вход по СМС с сохранёнными контактами и бонусами, оплата с брендами, экран «Билеты готовы» и отдельные состояния ошибок.

В v5 стили и шрифт взяты из живого виджета, а не придуманы: системный sans-serif, белые поверхности, серые карточки сеансов, синий `#0A7AFF` на активной дате, выбранных местах и основной кнопке. Из аудита остались сводка заказа, одно согласие, зоны зала, увеличенные кресла и понятные состояния ошибок. Основа и ограничения — в [docs/DESIGN-DIRECTION.md](docs/DESIGN-DIRECTION.md).

## Ограничения работы

- Экран успеха в живом виджете наблюдался (реальная продажа через API, адрес `/payment/success/<saleId>`, кадры `audit/live-success/`): QR, номер заказа, «Скачать билет». Реальный платёж не проводился, поэтому это экран оформленного заказа, а не подтверждение списания.
- События по шагам в текущем виджете отсутствуют, поэтому все численные эффекты в гипотезах — прогноз, а не замер. Первый шаг внедрения — события, затем изменения.
- Настройки кинотеатра (Пушкинская карта, аккаунт, промо) проверялись на этом конкретном кинотеатре; в других аккаунтах поведение может отличаться.
