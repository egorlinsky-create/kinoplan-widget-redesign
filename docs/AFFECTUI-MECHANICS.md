# Механики affectUI: что забрать в прототип «Киноплана»

Источник: [affectui.com/components](https://www.affectui.com/components) — библиотека React-компонентов для AI-продуктов, 151 компонент. Смотрел каталог целиком; ниже — не пересказ витрины, а разбор механик, которые переносятся в наш виджет, и готовые промты под наши секции.

## Механики, которые нам подходят

| affectUI | Механика | Куда у нас | Приоритет |
|---|---|---|---|
| Approval Card | Карточка с отсчётом, который **ставится на паузу**, риск-бейдж, морф в решённую строку | плашка брони: пауза счёта при возврате к местам и после ошибки оплаты; «бронь истекла» как морф из таймера | высокий |
| Button | **Shimmer** состояния загрузки внутри кнопки, а не спиннер снаружи | «Оплатить»/«Перейти к оплате» в момент обращения к банку | высокий |
| Checkbox | Галочка **рисуется** (stroke-dashoffset), ошибка — не только цветом | согласие на оформлении: отметка рисуется, ошибка с рамкой и алертом | высокий |
| Toaster | **Promise-toast**: спиннер → галочка, свать-дисмисс, стопка веером на hover | наш toast: «готовим билеты», «оплата не прошла», возврат билета | высокий |
| Segmented Control | Пилюля‑подложка **скользит** и слегка тянется, можно тянуть | сегменты «Телефон / Почта» во входе, «Карта / СБП» на оплате, лента дат в афише | высокий |
| Stat Card / Compact Breakdown | **Цифры прокручиваются** (digit roll), полоса скользит | сумма в сводке заказа и в кнопке «Оформить · 1 300 ₽» при смене мест | средний |
| OTP Input | Шейк при ошибке, авто-вставка из СМС, **морф в Verified** | СМС-код во входе | средний |
| Skeleton | Один общий **шейм** по всем серым фигурам, без мигания при быстрой загрузке | загрузка схемы зала и сеансов | средний |
| Badge | Живая точка **пульсирует**, пока что-то идёт | «лимит 6», «мало мест» в чипах сеансов | средний |
| Scroll Area | Тонкий скроллбар по hover, **мягкие фейды** у краёв, где есть прокрутка | зал на десктопе (у нас скрытый скроллбар) | средний |
| Dialog / Sheet | Фокус внутрь, Escape, возврат фокуса, лист на телефоне | панель входа | сделан, но фокус-ловушку проверить |
| Reaction Bar | Счётчики **прокручиваются по цифрам** | счётчик «выбрано 2 из 6» | низкий |
| Tooltip | Появление с задержкой, **без задержки при фокусе**, соседи — мгновенно | подсказка цены у кресла, тултипы панели | низкий |
| Hover Card | Открытие после паузы указателя, не на тач | превью фильма в шапке | низкий |

## Промты под наши секции

Формулировки ниже — рабочие: их можно отдавать в генерацию или в правку кода как есть.

1. **Плашка брони с паузой счёта.** «Сделай индикатор брони в шапке виджета: пилюля с иконкой часов и текстом «Держим билеты 14:57», моноширинные цифры. На последней минуте фон и рамка переходят в предупреждение, цифра пульсирует один раз в секунду с уважением к prefers-reduced-motion. Когда пользователь уходит на зал и возвращается, счёт не сбрасывается — визуально это показывает мягкая вспышка фона при возврате. По нулю — морф пилюли в состояние «Бронь истекла» и переход на экран с двумя действиями: «Выбрать места заново», «К афише»».
2. **Кнопка с shimmer и суммой.** «Кнопка основного действия с подписью «Оформить · 1 300 ₽», цифры табличные. При нажатии — shimmer-полоса внутри кнопки, спиннер не добавлять; при успехе галочка рисуется внутри кнопки, затем переход. При ошибке кнопка возвращается, а над ней появляется алерт-ошибка».
3. **Согласие с рисующейся галочкой.** «Чекбокс согласия: галочка рисуется за 180 мс, при ошибке секция подсвечивается рамкой ошибки, под строкой появляется алерт, фокус переходит на чекбокс, страница плавно доскролливается до него. Ошибка не передаётся только цветом — есть текст».
4. **Сегменты с плавающей пилюлей.** «Сегментированный переключатель из двух-четырёх пунктов: подложка скользит между пунктами за 220 мс, слегка растягивается при перетаскивании, активный текст меняет цвет синхронно. Работает с клавиатуры стрелками, один таб-стоп».
5. **Цифры суммы прокручиваются.** «Сумма заказа и цена в кнопке анимируются прокруткой цифр вверх при увеличении, вниз при уменьшении; разряды разделены пробелом, ширина колонки не прыгает (табличные цифры)».
6. **Toast-обещание.** «Тост «Готовим билеты»: сначала спиннер, после ответа — галочка с морфом, при ошибке — красная иконка и кнопка «Повторить». Свайп в сторону закрывает, несколько тостов складываются стопкой и разворачиваются веером при наведении».
7. **Схема зала с состоянием выбора.** «Схема зала: кресло при наведении поднимается на 1 px и получает мягкую тень, при выборе сжимается на 6 % и возвращается пружиной 260 мс; цена зоны подписывается у выбранных мест без сдвига самой схемы. При лимите мест лишние места коротко трясутся и рядом появляется алерт «За один заказ — до 6 мест»».
8. **Skeleton вместо пустого места.** «Пока схема зала не готова, вместо неё сетка серых кресел в тех же размерах с одним общим шеймом; при загрузке меньше 200 мс шейм не показывать, чтобы не мигать».

## Где у нас похожие секции

- `prototype/index.html` — `screen[data-screen="seats"]`: схема, легенда, панель выбора, липкий футер.
- `screen[data-screen="checkout"]` — карточки, согласие, способ оплаты, футер.
- `purchase-auth` (строки 68–123) — панель входа, сегменты, код СМС.
- `screen[data-screen="payment"]` — экран оплаты и статус проверки.
- `toast` и `hall-hint` — обратная связь; их и надо вести в модель affectUI (promise-toast, алерты по типам).
- Figma: компоненты `Алерт`, `Таймер`, `Кнопка`, `Способ оплаты`, `Чекбокс` — те же механики на стороне макета.

## Внедрено в прототип (26.11, 01:10)

- **Кресло**: при наведении поднимается и получает мягкую тень, при нажатии сжимается до 94 %, при выборе — пружина seat-pop 260 мс; для отказа приготовлена анимация seat-shake.
- **Кнопка**: состояние data-busy="true" показывает shimmer внутри кнопки, текст при этом скрыт, спиннер снаружи не добавляется.
- **Таймер**: последняя минута дышит мягким кольцом (	imer-pulse), без мигания.
- **Тост**: параметр состояния — data-state="loading" рисует точку спиннера перед текстом, чтобы показывать «готовим билеты» до ответа.
- **Суммы**: data-bind="total" и .sticky-cta__value прокручивают цифры к новому значению за 240 мс, строка при этом остаётся табличной и не прыгает по ширине.
- Всё под общим prefers-reduced-motion: reduce — анимации отключаются.
