## Договорённости

- «Один факт — один файл»: новая версия переписывает документ, история остаётся в журнале.
- Числа эффекта — прогноз, пока в живом виджете нет событий по шагам.
- Персонажи — гипотезы для аудита и интервью, не результат исследования.
- Всё за границами виджета (афиша, расписание, цена в карточке сеанса) — отдельное улучшение точки входа, не обязательная часть редизайна.
- Скриншоты не удаляются и не переименовываются: по ним собираются презентация и дизайн.

## UI Kit: правила ведения (Figma)

- Правила — блок «Служебные» (`361:220`) на странице `03 · UI Kit`, раздел «Правила ведения кита · для дизайнера и агента», 18 пунктов. Там же «Индекс компонентов» по node id.
- Эталон блока — Section «Кнопки» (`537:591`): заголовок 24/32, подпись 12/18, сетка мастеров (колонки — состояния, строки — типы, полосы — размеры), подписи осей, ниже карточка «Док · Кнопка».
- Геометрия сетки: шаг колонки = max(ширина) + 56, шаг строки = max(высота) + 28, между полосами размеров + 48. Подписи — текст в блоке, не в наборе.
- Ключевая грабля: у наборов вариантов в этом файле включён авто-лейаут — `x/y` вариантов игнорируются. Сначала `set.layoutMode = 'NONE'`, потом раскладка; иначе сетка не строится.
- Мастера живут в своём блоке; «Компоненты · …» отдельным фреймом не держим, инстансы — только в экранах. Архив — колонкой слева (`x = -2600`), скрыт.
- Колонка блоков: `x = 48`, ширина 1700, шаг 72 от нижней границы; рабочие узлы (Overlay, Схема зала, Шаблон экрана) — правая колонка `x = 2050`.
